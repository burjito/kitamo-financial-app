# Kitamo-Financial-App

## Project Overview
KitaMo is an AI-powered financial planning platform designed to help Filipinos make smarter decisions about their finances. The app provides personalized insights, goal tracking, product recommendations, and interactive tools to simplify financial management and planning.

## Features
- **AI-Powered Insights:** Get actionable financial advice tailored to your profile and goals.
- **Goal Tracker:** Set, monitor, and achieve your financial goals with smart recommendations.
- **Product Recommender:** Discover financial products that best fit your needs.
- **What-if Simulator:** Visualize different financial scenarios and outcomes.
- **Risk Profile Assessment:** Understand your risk tolerance and get matched with suitable products.
- **KitaBot:** Chatbot for instant financial guidance and support.
- **Secure Authentication:** Modern login and signup flows to keep your data safe.

## Usage
1. **Clone the repository:**
	```sh
	git clone https://github.com/burjito/kitamo-financial-app.git
	```
2. **Install dependencies:**
	```sh
	npm install
	```
3. **Run the development server:**
	```sh
	npm run dev
	```
4. **Open your browser:**
	Navigate to `http://localhost:3000` to use the app.

## Technologies Used
- **Next.js** – React framework for building web applications
- **TypeScript** – Type-safe JavaScript
- **Tailwind CSS** – Utility-first CSS framework
- **Supabase** – Backend as a service (authentication, database)
- **Genkit** – AI workflow orchestration
- **React** – UI library
